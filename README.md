# Workshop Inventory

Личный учёт инструментов и оборудования мастерской. Веб-приложение (PWA), интерфейс на русском.

**Текущая версия реализует:** каталог, карточки с фото, категории, поиск и фильтры, QR-коды (отдельная страница генератора, поиск предмета, PNG и печать 30/40/50/60 мм), сканер QR, IndexedDB, резервные копии JSON (импорт с объединением), корзина, светлая/тёмная тема, PWA.

**Пока не реализовано:** количественный учёт и движение остатков, полноценный журнал операций, настраиваемая иерархия мест хранения, пользовательские категории, облачная синхронизация.

**Дизайн:** тёмно-синяя неоновая тема по утверждённому макету, адаптивное меню, главная панель со статистикой реальных позиций, быстрые действия, категории, отдельные представления расходников и мест хранения, отчёты. Места хранения и категории берутся из существующих карточек; демонстрационные цифры не используются.

**Статусы полностью удалены.** При обновлении IndexedDB выполняется миграция v3, сохраняющая карточки и их постоянные QR-идентификаторы.

## Запуск
```
npm install
npm run dev      # разработка
npm run build    # проверка типов + сборка
npm test
```
Для хостинга в корне: `BASE=/ npm run build`. Для GitHub Pages (по умолчанию) путь `/Workshop-Inventory/`.

## Публикация
GitHub → Settings → Pages → Source: **GitHub Actions**. Каждый push в `main` собирает и публикует сайт.

## Важно
- Данные лежат в IndexedDB конкретного устройства и на другое устройство сами не попадают. Переносите через резервную копию.
- QR содержит только ссылку с случайным ID, без сведений о предмете. На чужом устройстве карточка не откроется, пока там нет этих данных.
- Фото сжимаются до 1280 px; оригиналы остаются в галерее телефона.

## Обновление интерфейса (v0.6)

Тёмная панель с линейными иконками, кнопка «Добавить» с выбором инструмента или расходника, цветные категории, плитки мест хранения, двухколоночный каталог на ПК, складской количественный учёт со свайпами, массовая печать QR, настройка виджетов и акцентного цвета. Прежние сведения карточек и постоянные QR ID сохраняются; база обновляется через Dexie version 4. Облачной синхронизации пока нет.

Поля серийного/инвентарного номеров, цены и покупки, статусы, ремонты, обслуживание и выдача не возвращались в интерфейс. Исторические скрытые поля в существующих записях остаются для сохранности данных.
